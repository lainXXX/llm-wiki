# 常见坑 — 症状 / 原因 / 处理

## 1. 幻觉句子

**症状**：页面里出现源里没有的结论、或者链接指向不存在的页。
**原因**：模型在"补全"知识，而不是"编译"源。
**处理**：删掉无法归属的句子；确实有价值的推测标 `（推测）`；链接目标不存在就拒绝写入。可溯源与链接依据见 SKILL.md「边界」，编辑既有页的三种允许动作见 `ingest.md`。

## 2. wiki 膨胀

**症状**：几百个一次性页面，index 变垃圾场。
**原因**：query 结论静默归档；或者把弱关联概念都建了独立页。
**处理**：归档**必须**问用户（`query.md` 步骤 6）；新页门槛是"被 ≥2 个源引用或用户显式要求"；entity 需 ≥3 个具体属性或 ≥2 个关联。lint 的"30 天无人引用的 draft"是删除候选。

## 3. 单次 ingest 烧穿上下文

**症状**：写到一半输出截断、wiki 半损坏且不可审计。
**原因**：一次循环改十几个文件。
**处理**：触及上限就中止，不硬扛（上限见 SKILL.md「边界」）；弱关联写进 `wiki/log.md` 的 `## TODO Updates` 分批次消化。

## 4. 静默覆盖用户的改动

**症状**：用户手改过的内容消失。
**原因**：agent 信任自己上下文里的旧版本，直接 Write 覆盖。
**处理**：**任何 Edit 之前必须先 Read**；既有页只做区块级追加，禁止整页重写。

## 5. 契约漂移

**症状**：`AGENTS.md` 与实际页面结构越来越不一致，或悄悄被改了；或库停在旧契约版本而 agent 按新版行事。
**原因**：agent 为了"顺手"改了约定；或 skill 升级了但存量库没跟上。
**处理**：
- 改 `AGENTS.md` 的**领域区必须**用户同意；**契约区**的改动一律**先给 diff**（见 SKILL.md「必须问用户的事」）。改完记 `wiki/log.md` 并 commit。
- lint 报 `契约版本落后` 时：读 skill 的 `references/agents-template.md`，把差异**整理成 diff 提议**交用户确认——**不要整文件覆盖**，那会抹掉用户的手改（协同演化的对价，见 spec §4.2）。

## 5b. 页面放错桶

**症状**：lint 报 `桶错位`（Blocking），退出码 1。
**原因**：新建页时没查 `type → bucket` 映射（`AGENTS.md` §3）。
**处理**：按映射把文件 `git mv` / 移动到正确的桶，链接深度同时要改（同桶 `foo.md` ↔ 跨桶 `../concepts/foo.md`）。别只改 frontmatter 的 `type` 来"迎合"现在的位置——先想清楚哪个才是对的。

## 6. 阈值判据失效

**症状**：中文语料永远被判 S 档，索引越读越慢。
**原因**：用了 `wc -w × 1.3` 这类"看起来对"的判据。
**处理**：改用非空白字符数（`scale.md`）。新增任何阈值判据时，**必须用真实中文语料核一遍**。

## 7. index 漂移

**症状**：页存在但 index 里没有，或 index 指向已删的页。
**原因**：分步写入时漏了步骤 7c，或手改了页面没同步。
**处理**：lint 的 Blocking 项会抓；修完重跑。

## 8. `.bak` 残留

**症状**：wiki 里出现 `*.bak-<ts>`。
**含义**：**上次写入没收尾**——不是垃圾，是现场。
**处理**：先对照 `wiki/log.md` 的 `[IN PROGRESS]` 判断那次是否真失败，再决定还原还是删。成功路径上 `.bak` 会被立即删除，所以正常状态**不应存在** `.bak`。

## 9. 在更大的仓库里自动提交

**症状**：一次 ingest 的 commit 里混进了无关项目的文件。
**原因**：wiki root 落在某个更大仓库内部，`git add -A` 从仓库根生效。
**处理**：`wiki_commit.js` 检测到 root ≠ 仓库根时**拒绝提交**并说明。让用户手动在 root 范围内提交，或把 wiki 挪出那个仓库。

## 10. 重复 ingest 同一个源

**症状**：同一篇论文出现两个 source 页，内容翻倍。
**原因**：跳过了 `source_status.js` 前置检查。
**处理**：ingest 前**永远**先跑它；`unchanged` 就只报告"未检测到新内容"，不写任何文件。

## 11. 把模型知识当 wiki 内容回答

**症状**：用户问 wiki 里没有的东西，得到一段"看起来有引用"的回答。
**原因**：query 时把自身知识与 wiki 内容混在一起。
**处理**：明说"wiki 里没有 X"，把缺口记进 `wiki/log.md` 的 `[GAP]`。确实要用模型知识时另起一段并标注。

## 12. 越界写入

**症状**：项目目录里多出文件（指针文件、`CLAUDE.md` 片段）。
**处理**：任何写入前断言路径在 `<WIKI_ROOT>/` 内；发布版本**不写任何项目内文件**。硬保证是"项目目录内创建的字节数 = 0"。
